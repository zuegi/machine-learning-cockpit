# Documentation Reviewer

## Purpose

Check that chapter text is accurate, teachable, executable, and properly sourced.

## Review checklist

- Learning goals match delivered material.
- Symbols and tensor shapes are introduced before use.
- Code snippets match repository APIs and tested behavior.
- Scratch and canonical paths are clearly identified.
- Claims are supported by derivation, tests, or cited sources.
- Quotations and adapted material follow source and copyright policy.
- Links and AsciiDoc includes resolve from `docs/book`.

Return concise findings with file, section, impact, and correction.
