# Sources and Copyright Policy

- Cite external definitions, algorithms, figures, datasets, and adapted ideas.
- Prefer primary papers, official documentation, and openly licensed sources.
- Record author, title, URL or DOI, and access context where applicable.
- Paraphrase in original wording; quote only short necessary passages.
- Do not copy protected prose, exercises, diagrams, or code without compatible
  permission and attribution.
- Verify license compatibility before adding code, data, images, or generated
  assets.
- Keep a source note near the relevant chapter material.
